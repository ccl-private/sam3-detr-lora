# 道路标线初步可行性结果

日期：2026-08-17

## 模型

- 来源：只读权重 `efficient_sam3_tinyvit_s.pt`
- 运行时架构：TinyViT-S 与无参数固定提示词表
- 导出预训练包中的浮点数数量：56,135,626
- 可训练参数量：4,292,865
- 导出的 FP16 预训练包：110.14 MiB
- 第 0 轮 LoRA 权重：约 95 MiB

## 训练

- 数据集：9,351 张训练图片和 2,343 张验证图片
- 损失：带一对多匹配的 SAM3 原生损失
- 四张 GPU，每卡批大小 2，BF16 混合精度，分辨率 1008
- LoRA 秩 8、alpha 16、dropout 0.05
- 学习率 2e-4，AdamW 权重衰减 1e-2
- 第 0 轮验证损失：9.388181
- 实测每个进程的 GPU 显存：约 19.4--25.7 GiB

原计划进行三轮训练；为在投入更多算力前验证可行性，任务在第 0 轮验证完成后主动停止。

## 置信度阈值 0.5 下的前十张道路标线图片

| 提示词 | 基础模型检测数 | 第 0 轮检测数 | 第 0 轮平均分数 |
|---|---:|---:|---:|
| white solid lane line | 0 | 77 | 0.5956 |
| white dashed lane line | 0 | 49 | 0.6141 |

微调明显恢复了基础模型原本为零的领域响应。实线掩码通常能沿长道路边界生成，但仍存在重复掩码和道路边缘误检。虚线掩码能够定位真实虚线，但召回率依然偏低。继续训练更多轮次是合理的，不过当前单轮权重尚不能与完整 SAM3 LoRA 结果竞争。
