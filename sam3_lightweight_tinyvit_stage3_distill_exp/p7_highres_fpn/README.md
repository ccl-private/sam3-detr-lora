# P7 高分辨率FPN直接融合实验

## 目标

P7以道路标线实际IoU最佳的`weights/p6_stage1_frozen_p5.epoch8.pt`为起点。P6两类平均IoU为0.5912，但Stage 1/2细线特征最终都先融合到`1024×72×72`，高分辨率信息仍经过压缩。

P7复用P6已经训练好的横向、纵向DSConv方向特征，不重复执行`grid_sample`：

```text
Stage1 横/纵特征（2×64通道，126×126）
    → 新增1×1投影 → 256×288×288 → 零门控 → FPN[0]

Stage2 横/纵特征（2×128通道，63×63）
    → 新增1×1投影 → 256×144×144 → 零门控 → FPN[1]

原P6低分辨率残差和FPN[2]保持不变
```

保留P6低分辨率残差是为了保证P7初始化严格等价于P6 epoch 8。P7第一阶段冻结TinyViT、全部LoRA、DETR、输出头、FPN和P5/P6分支，只训练两个FPN投影、归一化和独立门控。

## 双门控如何工作

门控的通用定义、零初始化时的首步梯度行为以及正负值解释已经在`../p6_multiscale_dsconv/README.md`中首次完整说明。P7沿用同一残差门控思想，但新增门控控制的是高、中分辨率FPN注入，不替代P6原有的Stage 1/2低分辨率门控。

P7有两个互相独立的可学习标量门控：

- `gate_high`控制Stage 1方向特征注入`288×288`的FPN[0]。
- `gate_mid`控制Stage 2方向特征注入`144×144`的FPN[1]。

融合公式为：

```text
FPN[0]_out = FPN[0]_P6 + gate_high × Adapter_high(Stage1方向特征)
FPN[1]_out = FPN[1]_P6 + gate_mid  × Adapter_mid(Stage2方向特征)
FPN[2]_out = FPN[2]_P6
```

两个门控都初始化为0，因此P7挂载后新增残差为0，初始输出严格等价于P6 epoch 8。第一个优化step中，门控本身可以从损失获得梯度；投影和归一化参数由于被零门控截断，梯度为0。门控离开0后，从第二个step开始，投影、归一化和门控都能获得梯度。这是有意采用的无扰动初始化，不是梯度异常。

门控是无约束标量：正值表示按当前投影方向加上残差，负值表示减去残差。由于投影权重本身也能改变符号，门控的正负不能单独解释为有益或有害，主要观察绝对值和实际IoU：

- `|gate|`长期接近0：模型整体上基本没有采用该尺度分支。
- `|gate|`稳定增大：该尺度正在明显改变FPN特征。
- 门控增大但实际IoU不升：不能据此认定分支有效。
- 门控剧烈振荡：可能是门控学习率过高或该尺度梯度冲突。

当前每个尺度只用一个标量同时控制全部256个输出通道。这种设计参数少、初始化安全，适合先判断整个尺度是否有总体价值，但不能独立选择有用通道。只有标量门控验证受限后，才考虑改为256通道门控；不能在本阶段同时修改，以免无法归因。

## 训练

```bash
bash sam3_lightweight_tinyvit_stage3_distill_exp/p7_highres_fpn/scripts/train_p7_highres_fpn.sh
```

默认四卡、每卡batch 2、10轮并逐轮保存。继续保留真实标签监督、最终输出蒸馏和三尺度图像特征蒸馏。

输出：

- 日志：`logs/p7_highres_fpn_frozen_p6/`
- 最佳验证损失权重：`weights/p7_highres_fpn_frozen_p6.best.pt`
- 逐轮权重：`weights/p7_highres_fpn_frozen_p6.epochN.pt`

## 判定标准

统一使用相同10图、7提示词、阈值0.5。P6 epoch 8基线为：实线IoU 0.6214、虚线IoU 0.5610、平均IoU 0.5912。

P7平均IoU至少达到0.6112，并且虚线IoU不下降，才认为高分辨率直接融合具有明确价值。若只降低特征KD而实际IoU不提高，应停止，不继续开放LoRA。

## 已完成验证

- neck四级实际输出为`256×288×288`、`256×144×144`、`256×72×72`、`256×36×36`；SAM3当前训练使用前三层。
- Stage 1方向特征为`128×126×126`，对齐到FPN高分辨率层；Stage 2方向特征为`256×63×63`，对齐到FPN中分辨率层。
- 总参数105,986,786，新增且可训练参数99,330；P6和其他旧参数均冻结。
- 高、中门控均为0时，P7与P6 epoch 8的四级neck输出逐元素一致，所有层最大绝对误差为0。
- 两batch冒烟首步只有门控有梯度；第二步两个投影、归一化和门控均有非零梯度。
- 冒烟checkpoint包含8个P7张量，可以由统一评测脚本自动挂载P5、P6、P7并完成7提示词推理。

## 正式结果与结论

P7从P6 epoch 8开始完整训练10轮，实际任务指标随训练缓慢提高，epoch 9最佳：

| 指标 | P6 epoch 8 | P7 epoch 9 | 变化 |
|---|---:|---:|---:|
| 白实线IoU | 0.6214 | 0.6319 | +0.0106 |
| 白虚线IoU | 0.5610 | 0.5687 | +0.0077 |
| 两类平均IoU | 0.5912 | 0.6003 | +0.0091 |
| 白虚线Recall | 0.6524 | 0.6604 | +0.0080 |

epoch 9验证指标为`val/loss=9.2771`、`val/supervised=5.3814`；斑马线误检11、护栏误检0。最佳任务权重为`weights/p7_highres_fpn_frozen_p6.epoch9.pt`，不是按验证loss保存epoch 8的`.best.pt`。

最终`gate_high=-0.0171`、`gate_mid=0.7620`。模型明显采用Stage 2到`144×144`的中分辨率直连，但几乎不采用Stage 1到`288×288`的简单投影。P7有稳定小幅收益，但没有达到预设平均IoU 0.6112，因此不追加训练，也不直接开放LoRA。下一步改为在输入侧504分辨率先提取细线再下采样，同时预留普通长条卷积严格对照。
