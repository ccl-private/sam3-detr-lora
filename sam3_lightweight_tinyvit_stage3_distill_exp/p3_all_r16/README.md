# P3 全部LoRA统一r16实验

本实验从P2最佳权重继续，同时提高图像侧和DETR侧LoRA容量：

- TinyViT stage 1、2、3：r8、alpha16改为r16、alpha32。
- DETR Encoder/Decoder注意力与FFN：r8、alpha16改为r16、alpha32。
- 点积分类头和分割头：完整继承P2，不改变结构。
- 三尺度图像特征蒸馏和P0最终输出蒸馏保持不变。

由于r8与r16矩阵形状不同，不能直接加载。转换脚本会先把P2的图像r8和DETR r8增量分别合并进对应基础权重，移除全部旧LoRA，再给图像编码器与DETR统一挂载零增量初始化的r16 LoRA。这样转换后的初始能力应与P2基本一致，同时给后续训练提供更高低秩容量。

## 执行顺序

```bash
bash sam3_lightweight_tinyvit_stage3_distill_exp/p3_all_r16/scripts/convert_all_lora_rank.sh
bash sam3_lightweight_tinyvit_stage3_distill_exp/p3_all_r16/scripts/train_p3_all_r16.sh
```

输出：

```text
../weights/p3_all_r16_init.pt
../weights/p3_all_r16.best.pt
../weights/p3_all_r16.pt
../logs/p3_all_r16/
```

## 已完成验证

- 权重转换：成功合并40个图像r8模块和84个DETR r8模块，并重新挂载相同数量的r16模块。
- 转换初始化权重：`../weights/p3_all_r16_init.pt`。
- 参数量：总参数105,844,922，可训练参数5,792,001。
- 单图一致性：P2→P3初始化的白实线IoU为0.5373→0.5334，白虚线为0.3978→0.3989；没有出现能力断裂，差异来自合并后的浮点运算与阈值边界。
- 单步训练与验证：已经通过。
- 单步梯度范数：DETR LoRA 63.03、图像LoRA 56.81、输出头76.99，三部分均有有效梯度。
- 单步验证：`val/loss=11.1124`、`val/supervised=6.5589`、图像特征KD为0.3466。

## 正式训练结果

- 完成轮数：10轮（epoch 0～9），没有提前停止。
- 最佳权重：`../weights/p3_all_r16.best.pt`。
- 最佳点：epoch 3。
- 最佳`val/loss`：10.0335，P2最佳为10.1169，下降0.0834。
- 最佳`val/supervised`：5.9835，P2最佳为6.0514，下降0.0679。
- 最佳图像特征KD：0.3315。
- epoch 3之后`val/loss`在10.04～10.12之间波动，继续训练没有形成持续改善。

## 实验结论

统一提高LoRA秩可以降低验证loss，但没有带来有意义的道路标线提升。平均IoU只增加0.0010，白虚线IoU与Recall反而略降，因此当前主要瓶颈不是LoRA秩。后续不建议继续提高到r32；更值得测试的是解冻TinyViT高层与neck，或者针对白虚线召回重新设计数据和损失。
