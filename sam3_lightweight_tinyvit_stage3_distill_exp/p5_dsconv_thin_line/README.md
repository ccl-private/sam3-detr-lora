# P5 DSConv高分辨率细线分支方案

## 当前状态

P5-A已经完成实现、20轮正式训练和逐轮统一测试。P5相关模型代码、配置、脚本和说明都放在本目录；权重、日志和测试输出继续放在TinyViT实验根目录既有的`weights/`、`logs/`和`tests/output/`中，且不提交Git。

这里的DSConv指动态蛇形卷积（Dynamic Snake Convolution），不是普通深度可分离卷积。P5目标不是继续扩大LoRA容量，而是给TinyViT增加适合细长、弯曲和弱纹理目标的高分辨率结构先验，重点改善白虚线和远距离车道线。

## 实验动机

已有实验说明：

- P2把图像LoRA扩展到Stage 1/2/3后，平均IoU达到0.4553，是当前更稳妥的TinyViT基线。
- P3把图像与DETR LoRA统一提高到r16，平均IoU仅为0.4563，提升0.0010，说明LoRA秩不是主要瓶颈。
- P4完整解冻Stage 3与FPN neck后，最佳平均IoU降至0.4422，说明直接扩大视觉参数更新范围无效。
- TinyViT P2的白实线Recall为0.7145，白虚线Recall只有0.4461；Base对应0.7883和0.8226。主要差距集中在断续、窄小和远距离结构。

因此P5不继续修改低分辨率Stage 3，而是从较高分辨率特征接出细线分支，在细节被进一步下采样前提取方向连续性。

## 核心结构

第一版只使用TinyViT Stage 2特征，暂不同时接入Stage 1，避免显存、计算量和变量过多。

```text
TinyViT Stage 2高分辨率特征
          ├── 横向DSConv分支
          └── 纵向DSConv分支
                    ↓
               通道拼接
                    ↓
          1×1投影 + 归一化 + GELU
                    ↓
              可学习零门控
                    ↓
        加到对应尺度的FPN特征
                    ↓
             原DETR与mask head
```

实际代码确认TinyViT-11M的Stage 2下采样前特征为`256×63×63`，不是按名称预估通道。DSConv把该特征投影到`1024×72×72`，与学生投影头输出相加，再交给原FPN生成`256×288×288`、`256×144×144`和`256×72×72`三尺度特征。

融合形式：

```text
F_out = F_fpn + gamma * Align(F_thin)
```

`gamma`是可学习标量，初始化为0。这样加载P2权重后，新增分支初始不改变模型输出，可以先验证P2加载前后预测一致，再开始训练。分支输出的空间尺寸和通道数必须与目标FPN尺度显式对齐。

## DSConv定义约束

正式实现必须包含以下行为，不能用普通`Conv2d`替代后仍命名为DSConv：

1. 从输入特征预测每个卷积采样点的偏移。
2. 横向分支沿x方向排列采样点，纵向分支沿y方向排列采样点。
3. 偏移沿蛇形路径累积，使相邻采样点保持连续约束，而不是完全独立漂移。
4. 使用双线性插值采样，偏移预测、累积和采样全过程必须可反向传播。
5. 对偏移幅度设置上限，第一版建议`tanh`后乘可配置的`offset_scale`。
6. 记录偏移可视化接口，便于检查采样路径是否沿车道线而不是背景纹理移动。

第一版建议核长为9，只使用横向和纵向DSConv，不在同一个分支中混入普通卷积。两路输出通道保持一致。普通卷积只在DSConv初步有效后作为机制对照，避免第一轮增加不必要的结构。

## 分阶段实验

所有阶段都从同一个`weights/p2_image_stage123_r8.best.pt`开始。这里的“冻结LoRA”是保留P2已训练好的LoRA增量参与前向，只把参数设为不可训练；不能卸载或清零LoRA，否则起点不再是P2。

### P5-A：最小DSConv验证

第一阶段锁住所有已有模型参数，只训练新增DSConv分支和融合门控：

- TinyViT基础权重冻结。
- Stage 1/2/3图像r8 LoRA保留在前向中，但冻结参数。
- 原FPN neck冻结。
- DETR基础权重与r8 LoRA冻结。
- 点积分类头和分割头冻结。
- 只训练横向/纵向DSConv、偏移预测器、融合投影和`gamma`。

因为原P2参数完全不更新，不存在LoRA续训收益，P5-A可以直接与历史P2指标比较。先训练2轮，每轮保存checkpoint并统一评测。如果没有实际指标提升，P5到此停止，不增加普通卷积对照，也不开放LoRA。

### P5-B：普通卷积机制对照

只有P5-A明显提升后才实现P5-B。它使用与DSConv相同的Stage 2输入、融合位置、输出通道和门控，普通卷积分支的参数量应尽量匹配两路DSConv。P5-B同样冻结全部P2参数，只训练新增分支。

P5-B用于判断提升来自动态蛇形采样，还是任何新增高分辨率旁路都能获得。普通卷积不混入P5-A的DSConv分支内部。

### P5-C：LoRA联合适配

只有P5-A优于P2，并且P5-B证明DSConv具有独立收益后，才进行联合适配。开放顺序为：

1. Stage 2图像LoRA。
2. 必要时Stage 1图像LoRA。
3. DETR LoRA和分割头。

Stage 3图像LoRA最后考虑，第一版不完整解冻TinyViT或neck，避免重复P4已经失败的变量。P5-C必须增加一个不含DSConv、但开放相同LoRA和输出头并训练相同轮数的续训Control，才能扣除联合续训收益。

## 学习率与初始化

P5-A建议初始学习率：

| 参数组 | 学习率 |
|---|---:|
| 新增细线分支 | 1e-4 |
| 融合门控 | 1e-3 |

`gamma`保持0初始化，确保新模型加载P2后输出严格一致。此时第一个step中DSConv主体会被零门控截断梯度，只有`gamma`先获得梯度；从后续step开始，DSConv主体随非零门控获得梯度。这是有意选择，以可验证的无扰动初始化优先于第一个step的学习速度。

P5-C联合适配时建议：

| 参数组 | 学习率 |
|---|---:|
| DSConv细线分支 | 2e-5～5e-5 |
| Stage 1/2图像LoRA | 5e-6 |
| DETR LoRA | 1e-5 |
| 分割头 | 1e-5 |

所有阶段保持P2的真实标签监督、最终输出KD和三尺度图像特征KD不变。第一版不新增边界、骨架或连通性损失，先隔离结构变量。

## 损失与白虚线风险

DSConv倾向于强化方向连续性，但白虚线存在合法间隔，可能把相邻虚线错误连接，或者把裂缝、阴影和路缘连接成标线。因此：

- 第一版沿用真实实例mask监督，不能只使用教师的连续软mask。
- 不在跨实例区域加入强制连通损失。
- 实线和虚线继续作为不同文本类别监督。
- 统一评测除IoU和Recall外，还要查看虚线间隔是否被填充、实例数是否异常减少，以及斑马线和护栏负类误检。

若结构对照证明DSConv有效，再单独建立后续损失实验，讨论边界损失、中心线损失或实例内部拓扑约束；不能在P5第一版同时加入，以免无法归因。

## 验证步骤

实现后依次完成：

1. 打印Stage 2与目标FPN特征的实际形状，确认接入尺度，不凭名称猜测。
2. 用同一张图片比较P2与`gamma=0`的新模型输出，误差应接近数值精度范围。
3. 检查第一个step只有门控获得有效梯度，门控更新后再确认两路DSConv、偏移预测器和融合投影梯度均非零。
4. 检查偏移是否有限、无NaN/Inf，并输出采样路径可视化。
5. 记录P5-A新增参数量、峰值显存和实际推理延迟。
6. 完成P5-A两轮训练，每轮保存checkpoint并统一评测；只有通过后才继续P5-B和P5-C。

## 统一评测与判定标准

沿用相同10张道路图片、7个文本提示和0.5阈值，并额外保留阈值扫描。当前10图只包含白实线和白虚线真值，因此其他类别只用于观察误检。

P5-A进入下一阶段的条件：

- 相对P2两类平均IoU至少提高0.01；并且
- 白实线IoU不能下降超过0.01；并且
- 斑马线、护栏等负类误检不能明显增加，虚线合法间隔不能出现明显错误连接。

P5-B完成后，DSConv相对参数匹配的普通卷积分支还应使白虚线Recall提高至少0.015，才能认为蛇形采样具有独立收益。如果两种分支结果接近，结论应是“高分辨率旁路有效，DSConv没有独立收益”。如果DSConv只降低训练或验证loss而实际IoU不升，按P4经验判定无效。

## 资源与部署记录

P5不能只报告精度，还必须记录：

- 总参数量与新增参数量；
- 可训练参数量；
- checkpoint大小；
- 单图峰值显存；
- batch 1端到端延迟；
- 图像编码器、细线分支和其余模块的分段耗时。

DSConv使用动态偏移和插值采样，实际延迟可能高于相同FLOPs的普通卷积。即使精度提高，也必须确认目标推理后端能高效导出和执行；否则它只适合作为精度验证，不一定适合作为实时部署结构。

## 待确认后再实现

实现前需要最终确认以下默认选择：

1. 起点固定为P2最佳权重，不使用P3或P4。
2. 第一版只接Stage 2和一个FPN尺度。
3. P5-A保留但冻结全部P2 LoRA和其他已有参数，只训练两路DSConv、偏移预测、融合投影和门控。
4. P5-A先训练2轮，根据逐轮统一评测决定是否进入P5-B，不默认同时训练三组。
5. P5-B仅在P5-A有效后增加参数匹配的普通卷积机制对照。
6. P5-C仅在DSConv具有独立收益后开放Stage 2/1图像LoRA，再考虑DETR LoRA和分割头，并设置同条件续训Control。
7. 第一版保持P2损失不变，不加入新结构损失。

上述默认方案先回答“在完全不改变P2已有能力时，DSConv能否提供增量信息”，再按结果决定是否投入机制对照和联合适配。

## 冒烟验证

- Python语法、Shell语法和`git diff --check`通过。
- 默认128分支通道：总参数105,585,869，新增且可训练参数896,019；没有任何旧参数处于可训练状态。
- 实际形状：Stage 2输入`(1, 256, 63, 63)`，融合输出`(1, 1024, 72, 72)`。
- `gamma=0`时，P5与P2三尺度FPN输出最大绝对误差为0.0。
- 单步训练与验证在bf16混合精度下通过。
- 两个训练batch后，gate由0更新为非零；横向/纵向偏移卷积、采样投影和融合层权重均发生更新。
- 临时checkpoint包含14个P5分支张量，可以重新挂载分支并成功完成统一评测；评测模型名为`tinyvit_p5a_dsconv`，不会静默忽略分支。

### 训练模式修正

首次正式启动后发现P5的step级`train/loss`只有约7～11，而历史P2/P3通常为40～100。原因不是DSConv快速收敛，而是初版冻结逻辑错误调用了`detector.eval()`。SAM3根模块的`training`标志会控制Decoder辅助层、DAC和O2M输出；整体切到推理态后，这些训练监督被关闭，损失组成与P2不再一致。该轮训练已主动停止，产生的日志和checkpoint不作为正式实验结果。

修正后的约束：

- 参数冻结只通过`requires_grad=False`实现。
- SAM3根模块和Transformer保持训练态，以保留辅助层和O2M监督。
- 冻结的图像Backbone保持推理态。
- P2全部旧参数仍不可训练，只有P5分支和门控可训练。
- 代码加入运行时断言，训练模式再次错误时直接终止。

修正后相同batch规模的单步冒烟`train/loss=42.095`，两batch冒烟第二步为81.614，恢复到历史训练loss量级；第二步后gate、横向/纵向偏移卷积及其他分支权重均正常更新。验证阶段本来使用推理态，单个验证batch的绝对loss不用于和完整验证集均值比较。

## 正式训练

默认四卡执行：

```bash
bash sam3_lightweight_tinyvit_stage3_distill_exp/p5_dsconv_thin_line/scripts/train_p5a_dsconv.sh
```

脚本训练2轮并保存：

```text
weights/p5a_dsconv_frozen.best.pt
weights/p5a_dsconv_frozen.epoch0.pt
weights/p5a_dsconv_frozen.epoch1.pt
weights/p5a_dsconv_frozen.pt
logs/p5a_dsconv_frozen/
```

`.best.pt`仍按最低验证loss保存，最终必须逐轮运行统一10图评测并按实际IoU、白虚线Recall和误检选择权重。

### 20轮长期观察

为观察冻结P2、仅训练DSConv分支是否在更长周期内继续改善，另设从同一个P2最佳权重重新开始的20轮实验。它不是从两轮权重续训，学习率余弦周期按完整20轮重新计算；日志和权重使用独立名称，不覆盖两轮结果。

```bash
bash sam3_lightweight_tinyvit_stage3_distill_exp/p5_dsconv_thin_line/scripts/train_p5a_dsconv_20ep.sh
```

输出前缀为`weights/p5a_dsconv_frozen_20ep`和`logs/p5a_dsconv_frozen_20ep/`。每轮都保存checkpoint。长期实验重点观察验证指标是否在前几轮后平台或反弹，不以最后一轮作为默认最佳权重。

## 正式结果与结论

20轮训练在epoch 15取得最低验证损失并同时取得最佳实际任务指标：

| 指标 | P2基线 | P5 epoch 15 | 变化 |
|---|---:|---:|---:|
| 白实线IoU | 0.5454 | 0.5746 | +0.0292 |
| 白虚线IoU | 0.3652 | 0.4967 | +0.1316 |
| 两类平均IoU | 0.4553 | 0.5357 | +0.0804 |
| 白虚线Recall | 0.4461 | 0.5957 | +0.1496 |

epoch 15验证指标为`val/loss=9.5198`、`val/supervised=5.5815`、`val/kd=3.9383`。epoch 19平均IoU为0.5350，说明训练后期已经平台，没有必要追加轮数。统一10图中斑马线误检为11、护栏误检为0。

P5证明在完全冻结P2的条件下增加高分辨率细线旁路具有显著价值，尤其改善白虚线；但因为普通长条卷积P5-B尚未执行，不能把全部增益严格归因于动态蛇形偏移。后续P6为了优先提高最终能力，直接从P5 epoch 15扩展Stage 1分支。
