## 2. 为什么P12之后需要无标签数据

P0～P12虽然依次尝试了最终输出KD、三尺度图像特征KD、图像与DETR LoRA、细线分支、全部200个
候选集合及7提示软关系KD，但训练图片仍来自原有标注道路数据。历史固定10图又全部来自同一段
无人机视频的相邻帧，因此P12在该集合达到平均IoU 0.6670，并不能证明跨视角、天气和道路形态
已经稳定泛化。

无标签数据目录为：

```text
/slow_disk/ccl/data/roadline_unlabeled_distill/
```

当前候选池共591张、约250 MiB，包含城市多车道、航拍、高速、夜间、雨天、雪雾、乡村弯道、
磨损、遮挡和海外道路等形态。它们已经完成下载去重、解码检查以及官方Base/新Base教师对比，
但尚未进入任何P0～P12训练。

## 3. 与P12的关系

P12仍是当前轻量学生基线：

- 学生结构：官方TinyViT Stage-3加完整P8细线结构；
- 有标签损失：SAM3监督损失、最终输出KD、Presence KD和三尺度图像特征KD；
- P12新增：每个提示全部200个候选的集合/排序KD，以及以真实实例为锚点的7提示软关系KD；
- 固定10图平均IoU：0.6670；
- 新Base教师固定10图平均IoU：0.7483，仍相差0.0813。

P12依赖真实实例建立教师与学生的空间锚点。P13面对无标签图片时，必须改用新Base教师的高置信
实例作为伪锚点，不能假设存在GT，也不能把全部200个背景候选硬标成负样本。

## 6. P13损失设计

有标签batch继续使用P12损失，不改变监督基线：

```text
L_labeled = L_sam3_supervised
          + L_final_kd
          + L_presence_kd
          + L_image_feature_kd
          + L_candidate_set_kd
          + L_prompt_relation_kd
```

无标签batch第一版只使用新Base教师软目标：

```text
L_unlabeled = λ_presence * L_presence_kd
            + λ_class    * L_soft_class_kd
            + λ_box      * L_box_kd
            + λ_mask     * L_mask_kd
```

约束如下：

- [x] Presence使用连续logit和温度化概率，不先二值化。
- [x] 分类蒸馏保留教师软概率，不退化成one-hot伪标签。
- [x] 高置信教师实例与学生候选按分类、框和降采样软mask组合代价做Hungarian匹配，不按Query编号对齐。
- [x] mask使用连续logits计算BCE与soft Dice，不先阈值化成硬mask。
- [x] 无标签loss设置独立0.5总权重和前10%训练步warmup。
- [x] 有标签与无标签batch分别记录loss、分项loss、有效伪实例数和梯度范数。
- [x] P13-A未加入强增强、边界、骨架、Decoder逐层等额外变量。

### P13-A正式结果与判定

| 模型 | `val/supervised` | `val/kd` | `val/loss` |
|---|---:|---:|---:|
| P12 epoch 19 | 4.8458 | 4.5571 | 9.4029 |
| P13-A epoch 16 | 4.8242 | 4.5465 | 9.3707 |

P13-A相对P12只改善0.0216监督loss和0.0322总loss，训练域没有退化，但提升很小。591张无标签
网图在0.5阈值下的覆盖统计如下；检测数包含重复Query，图片没有人工真值，不能视为精度：

| 划分 | 图片数 | P12检测数 | P13-A检测数 | P12预测像素 | P13-A预测像素 |
|---|---:|---:|---:|---:|---:|
| 保留评测 | 100 | 1,301 | 21,285 | 2,768,419 | 15,027,427 |
| 训练候选 | 331 | 5,548 | 72,788 | 13,033,647 | 51,569,998 |
| 未入选 | 160 | 190 | 5,156 | 996,911 | 5,740,497 |

肉眼检查确认两件事同时成立：P13-A在雨夜、反光、磨损、航拍和远距离细线等真实道路图上补回
了部分P12漏检；P13-A也更容易在同一物体上输出多个Query和多个类别，并把箭头、文字、示意图、
车辆或反光当成道路标线。未入选图多数仍安静，但少量严重误触发拉高了总体计数。故当前判定为
“域外召回/激活增强，候选与类别校准明显退化”，不是已经通过验收的泛化提升。

根因优先指向无标签损失：只有教师高置信实例匹配后的学生Query被约束，其余学生Query可以自由
越过阈值；Presence又持续接受蒸馏。331张未清洗数据每轮约重复28次也可能放大该问题。

P13-A相对现有P12的最低验收条件：

1. 有标签验证和固定10图平均IoU不出现超过0.005的明确下降；
2. 域外人工标注子集平均IoU或Recall有可复核提升，而不是只增加候选数量；
3. 细白实线、白虚线等关键形态至少一项明显改善；
4. `car`回归不出现系统性归零；
5. 提升在至少两个随机种子或一次正式从头重训中复现。
