# TinyViT Stage-3 P0 与图像编码器 LoRA 实验方案

## 目的

验证现有 P0 效果受限是否主要来自冻结的轻量图像编码器。学生改为作者发布的 TinyViT-11M Stage-3 完整模型，并让高层视觉表示通过 LoRA 接受真实标签和 Base 教师的联合梯度。

## 初始化

- TinyViT 图像、文本编码器和完整 SAM3 头部来自官方 `efficientsam3_tinyvit_stage3.pt`。
- DETR LoRA、点积打分头和分割头从已有 EV-M 道路标线最佳 LoRA 迁移。两种 Stage-3 模型的 DETR 与头部结构一致，迁移已通过严格键检查。
- TinyViT 图像 LoRA 为新增参数，B 矩阵零初始化，因此训练开始时不改变官方 TinyViT 基模输出。

## 可训练模块

1. DETR Transformer Encoder/Decoder r8 LoRA。
2. TinyViT `layers.2`、`layers.3` 的注意力和 MLP r8 LoRA。
3. 点积打分头。
4. 分割头。

图像和文本编码器的原始参数保持冻结。图像前向不再放入 `torch.no_grad()`，以便图像 LoRA获得梯度；文本前向继续使用 `torch.no_grad()`。

## 优化参数

- 图像 LoRA：`1e-5`。
- DETR LoRA：`5e-5`。
- 打分头与分割头：`2e-5`。
- 每卡 batch size：2。
- 四卡全局 batch size：8。
- BF16 mixed precision。
- 训练 10 轮。

## 判断标准

需要与以下模型使用相同测试集、文本提示和阈值扫描比较：

1. 原 EV-M Stage-3 LoRA。
2. EV-M P0 最佳权重。
3. TV-M 零微调基模。
4. 本实验 TV-M P0 + 图像 LoRA。
5. Base DETR LoRA。

训练 loss 只用于诊断。最终判断依据为道路标线的实例匹配 IoU、召回率、精确率、误检数量及最佳阈值。
