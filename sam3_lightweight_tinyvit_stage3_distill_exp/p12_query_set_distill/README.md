# P12：道路标线候选集合与跨提示软关系蒸馏

P12以P9为严格基线：学生从作者官方TinyViT Stage-3与完整P8结构重新开始，教师继续使用“关闭域外纯负提示”的新Base教师；训练数据、7个道路标线提示、LoRA覆盖、图像特征KD、学习率、batch和20轮计划保持一致。P12不引入`car`、`person`或其他通用类别提示，也不引入任何域外hard negative。

## 要验证的问题

P9的最终输出KD只蒸馏教师和真值匹配的query。P12补充两部分、但仍只服务于道路标线类别：

- 候选集合KD：缓存每个道路标线提示全部Q个教师query的logit和框。经实测，本项目当前TinyViT Stage-3输出`Q=200`。教师高分候选与学生全部Q个候选按空间代价做Hungarian集合匹配，蒸馏soft logit和框；所有Q个候选则仅按排序后的置信度分布蒸馏，不假设教师和学生的query编号相同。
- 跨提示软关系KD：以每个真实道路标线实例为共同空间锚点，分别聚合教师和学生对全部7个道路标线提示的响应，得到7维软关系向量，再以温度KL蒸馏。它传递“该实例除本类外还像哪些道路标线类别”的信息。

原有GT匹配输出KD、Presence KD和三尺度图像特征KD均保留。P12不是开放类别恢复实验；`car`只在训练后相对当前新Base教师做回归检查，若额外损失明显，才另行做针对性蒸馏。

## 缓存与训练

先生成独立dense缓存。它不会覆盖P9缓存；缓存不保存全部Q个高分辨率mask，以避免不成比例的磁盘占用。

```bash
bash sam3_lightweight_tinyvit_stage3_distill_exp/p12_query_set_distill/scripts/cache_dense_teacher_queries_4gpu.sh
```

确认训练集、验证集缓存数量与图片数一致后执行：

```bash
bash sam3_lightweight_tinyvit_stage3_distill_exp/p12_query_set_distill/scripts/train_p12_query_set_4gpu.sh
```

## 初始超参数与判定

初始采用`topk=50`、候选集合权重`0.20`、全部Q个候选（当前实现为200个）排序分布权重`0.10`、跨提示关系权重`0.10`。三者均通过原有KD warmup逐步加入，避免第一轮被新增KD主导。

P12与P9比较时，主要看完整验证集监督损失、固定10图的分类别IoU/Recall和`car`相对新Base教师的回归结果。若道路标线平均IoU下降超过0.005或白虚线Recall明显下降，即使KD/loss下降也不接受该方案。

## 正式训练结果

四卡20轮已完成，最佳checkpoint为epoch 19：

- `val/supervised=4.8458`
- `val/kd=4.5571`
- `val/loss=9.4029`

P12的总损失额外包含候选集合KD和跨提示关系KD，不能把`9.4029`直接与P9的`8.5787`比较并据此判断退化。监督损失与P9的`4.8604`接近且略低，新增的约束主要体现在KD项中。

## 固定10图结果

统一使用阈值0.5。该集合只含白实线和白虚线真值，且10张图来自同一无人机视频的相邻帧，只用于历史回归。

| 模型 | 白实线IoU | 白实线Recall | 白虚线IoU | 白虚线Recall | 平均IoU |
|---|---:|---:|---:|---:|---:|
| P8 | 0.6772 | 0.7900 | 0.5960 | 0.6883 | 0.6366 |
| P9 | 0.6284 | 0.6869 | 0.6595 | 0.7543 | 0.6439 |
| P10最终epoch 9 | 0.5972 | 0.6502 | 0.6666 | 0.7607 | 0.6319 |
| **P12 epoch 19** | **0.6574** | **0.7187** | **0.6765** | **0.7755** | **0.6670** |
| 新Base教师 | 0.7520 | 0.8608 | 0.7445 | 0.8423 | 0.7483 |

P12比同起点、同教师的P9平均IoU提高0.0231：白实线IoU提高0.0291、Recall提高0.0318，白虚线IoU提高0.0170、Recall提高0.0212。它是当前固定10图上的轻量模型历史最好结果，但与新Base教师仍相差0.0813。

测试产物位于`tests/output/p12_query_set_best_first10_threshold_05/`，按仓库约定不提交Git。

网络图没有人工真值，下面只记录阈值0.5下的白实线/白虚线检测数量，不能作为IoU或误检结论。

P12没有恢复P9在城市多车道图中消失的白实线；白实线分布与P9完全相同，白虚线数量略有增加。测试产物位于`tests/output/external_roadline_p12_best_threshold_05/`，不提交Git。

## 正式结论

在固定10图上，补充全部Q个候选的集合/排序蒸馏和7提示软关系蒸馏有效，且实线、虚线同时改善；但两种新增KD在同一实验中一起引入，当前不能断言收益分别来自哪一项。跨形态网络图没有同步恢复城市白实线，因此P12可以作为新的固定10图最佳轻量checkpoint，不能据此宣称总体泛化已经超过P9或P10。若继续做严格消融，应分别关闭候选集合KD与跨提示关系KD。
